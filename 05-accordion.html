  • 1An opening line, then the detail. Each panel now leads with one sentence at a larger size. It gives the reader the point before they commit to the paragraph, and it gives editors a clear structure to write into — which makes a word limit far easier to hit.
  • Panels sit within a 60–90 word range. All four sections here have been trimmed to fit it, using your existing copy. That range keeps every panel roughly one screen deep with no scrolling inside the frame. The counts are an editor-side control only — see the CMS view below — and never appear on the live page.
  • Titles stay visible while reading, and the page height never changes as you switch section — the main irritation with a stacked accordion.
  • On mobile this collapses to a standard stacked accordion: same content, same order, one build. The word limit matters more there, since a long panel pushes the remaining titles well off screen.
  • Each section takes a permanent anchor, so it can be linked to directly from elsewhere on the site and opens already selected.

A soft stop warns but allows publishing, and trusts editors with the occasional exception. Given the aim is to stop these modules sprawling again, we would suggest hard on the title and soft on the body, at least for the first few months.
