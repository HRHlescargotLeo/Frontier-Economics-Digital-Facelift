Feature 05

Accordion

The ask: a refresh.

Currently on Who we are. The existing pattern works, but the closed rows give no clue what is inside them, the hairline rules and doubled borders make the spacing look uneven, and an opened panel indents its text away from the heading it belongs to.

Idea 1

Same pattern, properly tuned

The lowest-risk option: keep the full-width list, but add a teaser line to every closed row, align the panel text with its heading, and give the whole thing a consistent vertical rhythm.

  • 1Expand all. Useful when someone wants to read or print the whole section, and it helps search engines and screen readers reach content that is otherwise hidden.
  • 2Panel text aligns with its heading. The current indent breaks the connection between a title and its content, which is part of why the section feels loose.
  • A one-line teaser under each closed row means the visitor can decide what to open without guessing. Multiple rows can be open at once — the current behaviour.
  • Rules are single and consistent: one line between items, a heavier rule above the group. Vertical padding is one value throughout.
Idea 2

Index left, content right

All the section titles stay visible while you read, so it works more like a set of chapters than a stack of drawers. The page does not jump as panels open and close, which is the main irritation with long accordions.

Idea 3

Cards that can carry more than text

Each row becomes a bordered card with optional extras — a figure, an image, a link out. This turns the accordion from a place to hide long copy into a genuine content module, and it can absorb the “In numbers” content that currently sits separately on the page.
