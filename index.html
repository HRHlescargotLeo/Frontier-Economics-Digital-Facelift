Summary

What we changed, and why

Featured items
Image added above the tag and title so the card reads picture → context → headline → summary. The summary keeps its three-line limit unchanged — it was doing the work you valued. A single 16:9 crop is what holds the module together; items without artwork get a category block at the same ratio rather than a gap.
Banner
Kept as drawn. The overlap you flagged is resolved by the banner starting below the navigation rather than behind it, and the height is fixed in pixels so a larger monitor reveals more content instead of a bigger image.
People directory
Search sits above the grid and returns expertise as well as names; selecting an expertise result applies it as a filter rather than leaving the page, so search and filters stay one system. The rail, count, chips and first-person cards are unchanged.
People profile
Kept as drawn. Added type filters that appear only for people with six or more items, and drew the no-content fallback on the same template so it is a designed state rather than an assumption.
Accordion
Kept as drawn. Each panel opens with a single larger sentence, which gives editors a structure to write into and makes a 90-word limit realistic — all four sections fit it using your existing copy. Enforcing the limit itself is a CMS decision, so we've left that to your existing editor tooling and your developers' judgement, and noted our suggestion (hard stop on the title, soft warning on the body) as an open question below.
Image and text
Kept as drawn, photography removed. Tone alternates by position so editors never pick colours, and variants for two, three and four items come from the same component.
Next

Open questions for Frontier

The one-line person summary. Used on both the directory card and the profile. 423 people is a lot of copy — is it written for everyone, for senior staff only, or gradually? The card falls back to sector tags where it is missing, so a phased rollout works.
Hard or soft word limits. Our suggestion is hard on titles, soft on body copy for the first few months. Worth a decision before build, since it changes how the CMS behaves.
The icon set. The image-and-text tiles need roughly a dozen icons drawn as one family. Does an existing set exist that we should extend, or is this new work?
Author tagging. The profile aggregator is only as good as the tagging behind it. Worth auditing how consistently content is currently tagged to people before we rely on it.
Character limits against real content. Suggested limits are on each page. Testing them against your longest existing headlines before sign-off will save changing them later.
